# Smoke test ด้วยมือ (Assistant)

รายการนี้ต้องใช้ key จริงและต้องคลิกเอง จึงให้ผู้ใช้ทำ ทำตามลำดับ แล้วจด "ผ่าน/ไม่ผ่าน" ไว้ทุกข้อ

## เตรียมเครื่อง

1. ติดตั้ง dependency ของ UI (ครั้งแรกครั้งเดียว)
   ```powershell
   cd E:\Github\vyknnr-grokbot-app\ui
   npm --cache E:/Github/vyknnr-grokbot-app/.npm-cache install
   ```
2. เปิดแอปแบบ dev (เปิดหน้าต่างให้เอง และ build ใหม่เมื่อแก้โค้ด)
   ```powershell
   $env:CARGO_TARGET_DIR = "E:/Github/vyknnr-grokbot-app/target"
   npx tauri dev
   ```
   หรือใช้ไฟล์ที่ build ไว้แล้ว: `E:\Github\vyknnr-grokbot-app\target\debug\assistant-app.exe`
3. ข้อมูลแอปอยู่ที่ `%APPDATA%\com.local.assistant\` (`assistant.db`, `settings.json`) ส่วน key อยู่ใน Windows Credential Manager (ชื่อบริการ `com.local.assistant`)

## ตั้ง key

1. กด **ตั้งค่า** ที่มุมซ้ายล่าง
2. ช่อง **TypeSafe (Jev) API key**: วาง key แล้วกด **บันทึก** ป้ายต้องเปลี่ยนเป็น "ตั้งค่าแล้ว" และต้องไม่เห็นค่า key ที่ใดเลย
3. ช่อง **Anthropic API key**: ทำแบบเดียวกัน
4. ส่วน **สถานะตัวคุย**: API ต้องเป็น "พร้อมใช้งาน" ถ้ามี `claude` ใน PATH (ล็อกอินแล้ว) Claude CLI ต้องพร้อมด้วย
5. ตรวจว่ามีกล่องคำเตือนว่าข้อความและคำสั่งถูกส่งไป TypeSafe (Jev) และใช้ token

## เปิด Hermes API server (สำหรับข้อ 5, 8-11 และการใช้ Hermes)

1. ในหน้าตั้งค่า กด **แสดงข้อความตั้งค่า Hermes** แล้วกด **คัดลอก**
2. นำส่วน `mcp_servers:` และ `agent: disabled_toolsets:` ไปใส่ใน `~/.hermes/config.yaml` (ถ้ามี key `agent:` อยู่แล้ว ให้รวมเข้าด้วยกัน อย่าให้ซ้ำ)
3. ใน `~/.hermes/.env` ใส่
   ```
   API_SERVER_ENABLED=true
   API_SERVER_KEY=<ตั้งค่าสุ่มยาว ๆ ของคุณเอง>
   ```
4. รัน `hermes gateway` (ค่าเริ่มต้นฟังที่ `http://127.0.0.1:8642/v1`)
5. กลับมาที่แอป ใส่ค่าเดียวกับ `API_SERVER_KEY` ในช่อง **Hermes API key** แล้วกด **ตรวจใหม่**
6. Hermes ต้องเป็น "พร้อมใช้งาน" ถ้าขึ้น "ต้องปิด toolset: ..." ให้ปิด toolset ที่ระบุ (`hermes tools` หรือ `agent.disabled_toolsets`) แล้วรีสตาร์ต gateway
7. ตรวจว่า `timeout` ของ MCP server `assistant` ใน `~/.hermes/config.yaml` ไม่น้อยกว่า 450 วินาที (ข้อความตั้งค่าใส่ `timeout: 450` ไว้แล้ว) เพราะคำสั่งหนึ่งอาจรอผู้ใช้อนุมัติได้ถึง 300 วินาทีและรันได้อีก 120 วินาที ค่าเริ่มต้นของ Hermes (300) สั้นเกินไป

หมายเหตุ: ถ้าแอปแจ้งว่าเปิด MCP server ที่พอร์ต 8765 ไม่ได้ ให้เปลี่ยน **พอร์ต MCP server** ในหน้าตั้งค่า บันทึก ปิดแล้วเปิดแอปใหม่ แล้วคัดลอกข้อความตั้งค่า Hermes ใหม่ (URL เปลี่ยน)

## ข้อเพิ่มเติมที่ควรลอง

- ระหว่างตัวคุยกำลังตอบ กด **หยุด**: การตอบหยุด มีข้อความ "ผู้ใช้หยุดการตอบ" และคำสั่งที่กำลังรันถูกยกเลิก
- ระหว่างมีกล่องอนุมัติค้างอยู่ ลบแชตนั้นจากแถบซ้าย: กล่องหายไปและคำสั่งไม่ถูกรัน
- เปลี่ยนชื่อแชต (ปุ่มดินสอ) และค้นหาด้วยคำที่อยู่ในข้อความ
- เปิดโหมดมืดของ Windows: สีของแอปเปลี่ยนตาม

## ถ้ามีปัญหา

- รันจาก PowerShell (`target\debug\assistant-app.exe`) เพื่อดูข้อความ error ใน console
- แอปไม่เขียน key ลง log หรือไฟล์ใด ๆ ถ้าเจอ key ในไฟล์ใด ให้ถือว่าเป็น bug ร้ายแรงและแจ้งทันที
